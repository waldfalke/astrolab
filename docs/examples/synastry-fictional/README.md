# Вымышленный пример синастрии

Алия и Марек — вымышленные люди. Их даты, места рождения и контекст придуманы для
проверки полного пути Astrolab; пример не содержит личных данных реальных людей.

Это синастрия двух деловых партнёров. Она показывает, что один расчёт пригоден не
только для романтической пары: предмет разговора задаёт вопрос, но не меняет
астрологические данные.
