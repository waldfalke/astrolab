# Приёмка хорарного рецепта: вопросы и трудные развилки

Проверочные сценарии к [horary-v1](../horary-reading-recipe.md).
Это вымышленные ситуации и методические контрпримеры, не предсказания по реальным
людям. Они проверяют способность исполнителя применить рецепт. Тест числа полей
в JSON не заменяет такую проверку.

## Приём вопроса

| Случай | Ожидаемое действие | Признак провала |
|---|---|---|
| «Получу ли эту должность по текущему конкурсу?»; известна компания, конкурс ещё идёт | Принять один вопрос; I/X; предложение должности — проверяемый исход | Отвечать о призвании вообще или назначить VI по слову «работа» |
| «Получу должность и помирюсь с сестрой?» | Разделить, уточнить приоритет; не выдавать два хорара из одной карты | Сосчитать один знак вопроса и принять как единое дело |
| «У нас есть будущее?» | Уточнить, что человек хочет понять: продолжение общения, отношения, брак; не выбирать за него | Выдать прогноз брака на смутный вопрос о контакте |
| «Когда он точно вернёт долг?» | Уточнить сумму/должника/основание; сначала возможность возврата, затем срок | Сам вопрос уже посчитан подтверждением возврата |
| «Где мои ключи?»; потеря реальна | Принять поисковый вопрос, исследовать II и специальные правила; отделить возможность найти от подсказок о месте | Отказать только потому, что вопрос не бинарный, или выдать точный адрес по символике |
| «Куплю ли именно эту квартиру у этого продавца?» | I/VII/IV и цена по выбранной схеме; ответ о сделке | Продавец, квартира и деньги слиты в один сигнификатор |
| «Он глупый человек?» | Уточнить конкретное дело/поведение; не делать интеллектуальный диагноз | «Меркурий в падении → да» |
| Повтор того же вопроса через час из-за ответа «нет» | Вернуться к прежнему моменту для проверки; не искать другой ASC | Новая карта без изменившегося дела |
| Тот же договор после документированного изменения условий и контрагента | Допустимо новое рассмотрение с сохранённой связью с прежним вопросом | Старый ответ переписан задним числом либо любой повтор запрещён навсегда |
| «Краснодар, 23:56», даты нет | Запросить дату до расчёта; не взять текущую автоматически | Выдать точное колесо по догадке |

## Допуск и ход суждения

| Случай | Ожидаемое действие | Признак провала |
|---|---|---|
| ASC 1°; все остальные данные известны | Рассмотреть стадию дела и точность; аргументировать допуск/ограничение/отсрочку до исхода | Автоматический отказ или полное игнорирование раннего ASC |
| Сатурн в VII в вопросе о браке, одновременно хозяин VII | Исследовать реальную роль; не считать одно положение независимыми двумя запретами | «Нельзя судить, астролог ошибётся» без разбора предмета |
| Нет согласия часа по всем выбранным основаниям | Явно сохранить отсутствие и вынести методическое решение | Поставить «радикальна», потому что хочется прочесть |
| Восход/закат недоступны при поддерживаемой геометрии домов | Час неизвестен; никаких подставленных равных часов | `unavailable` стало ложным `нет согласия` либо успешным `pass` |
| Куспиды Regiomontanus идут обратно или не разбивают круг | Вычислительный отказ адаптера до домов/секты/SVG; не оценивать радикальность по неверным фактам | Успешный отчёт, подмена системы либо астрологический `defer` вместо ошибки расчёта |
| Луна без точного аспекта до ингресса, но есть текущее приложение в орбе | Развести два определения VOC и показать влияние | Один булев флаг определяет исход и срок |
| Луна без курса в Тельце | Рассмотреть оговорку Лилли вместе с главными сигнификаторами | «VOC → всегда отказ» либо «Телец → всё получится» |
| Сканирование окончилось до нужного события | Расширить диапазон или ограничить вывод | Пустой список значит «никогда» |
| Разделение старше трёх дней не попало в исходный охват | Увеличить `past_days` на прежнем моменте, сохранив вопрос/место; проверить фактическую цепочку | Сдвинуть карту назад или объявить отсутствие прежнего контакта |
| Сигнификаторы сближаются, но один разворачивается до корня | Зафиксировать станцию и несостоявшийся путь, проверить альтернативы | Линейно поделить орб на скорость и назначить дату |
| Луна сначала соединится с A, потом с B, оба контакта ещё впереди | Рассмотреть будущую цепочку и условия; не назвать уже существующей передачей | Два будущих корня автоматически дают совершенствование текущей карты |
| Есть более ранний аспект к третьей планете | Выяснить роль/приём и что именно он препятствует совершить | Каждый промежуточный аспект объявлен запретом |
| У двух домов один управитель | Сохранить совпадение, обосновать дополнительный носитель либо предел различения | Переназначить дом, чтобы получить удобную пару |
| Сильный взаимный приём без датируемого пути | Сохранить довод, проверить школу и возможность события; отдельно предел срока | Срок выдан только по слову «взаимный» |
| После ингресса изменились достоинства и фазовое состояние | Пересчитать и объяснить, что поменялось в условиях | Старая фаза/рецепция приклеена к далёкому контакту |
| Пример: в вопросе о возобновлении общения рассчитана будущая перемена рецепции несущего сигнификатора | Показать до/после, вклад в возможность контакта и условную ветвь; отделить охват скана от горизонта вопроса и условия пересмотра | Дата перехода объявлена гарантированным возвращением человека либо продлевает прежний вывод без проверки условий |
| Пример: в поиске вещи значимое состояние уже действует в момент вопроса; перемена видна внутри горизонта, конец состояния не рассчитан и даты обнаружения нет | Показать продолжающееся состояние и смысл перемены, сохранить открытый край; при важности расширить прошлое/будущее той же карты; допустима одна точка без окна | Края скана выданы за начало/конец явления, перемена стала датой гарантированного обнаружения либо вся временная картина отброшена без даты итога |
| Пример: после разбора предстоящей поездки человек просит выбрать момент отправления | Явно выделить элекционный запрос, определить управляемый акт, место и ограничения; сохранить исходный хорарный ответ | Элекция незаметно подменила ответ о поездке либо добавлена вместе с наталом без запроса |
| Классический вывод неудобен, а фазовое описание приятно | Проверить смысловое уточнение, сохранить противоречие | Фаза «отменила» отсутствующее совершенствование |
| `vector=null`, но Z/z/D присутствуют, H/h недоступны | Прочесть доступные состояния реальных носителей по ядру sources, оба цикла Mercury/Venus | Выбросить весь фазовый слой или подставить чужую домовую рамку |
| `defer` записан до суждения | Выдать причину и необходимое уточнение; без скрытого прогноза | После отказа всё равно появилась уверенная трактовка |

## Что было проверено при создании комплекта

Сценарии разобраны автором комплекта по правилам рецепта; независимый прогон
другой моделью здесь не выполнялся. Числовой тест использует вымышленный вопрос
с реальным небом 15 января 2026, Лондон. Он проверяет локальные эфемериды,
геометрические дома, покрытие лунного ингресса, корни, час и отсутствие
автоматического вердикта — не получение кем-либо должности.

Для дальнейшей приёмки дать исполнителю только вход, рецепт и его достижимые
ссылки. Сначала получить вопрос/допуски/twin, затем текст. Сравнивать смысл ответа
и пропуски, а не число заголовков. Ошибка в любом из двух допусков не исправляется
литературным качеством отчёта.
