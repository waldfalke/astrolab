# Пример: небольшой комплект без карты

**Все сведения ниже вымышлены.** Это иллюстрация различения оснований и слоёв,
не профиль автора проекта, не шаблон личности и не материал для реального пользователя.
Полная инструкция создания: [READ2PLAY](READ2PLAY.md).

## Исходный материал

Вымышленный пользователь сообщает: «Сначала люблю поработать молча. В разговоре
легче оценить две конкретные альтернативы, чем длинный список. Но когда изучаю
неизвестную область, широкий обзор мне полезен. Вчерашнюю усталость не надо
записывать как свойство моего характера». Астрологию включать не просит.

## Возможный STARS.full.md

```markdown
# Личный контекст — полное основание

Редакция: 2026-09-12. Сокращённый вход — STARS.md рядом с этим файлом.
Основание: предоставленное самоописание. Наблюдений вне него и данных карты нет.
Астрологический слой отсутствует.

## Обсуждение после самостоятельной работы

Самоописание: предпочитает сначала подумать молча. Из этого не следует отказ
от сотрудничества или требование никогда не задавать вопросы.

## Альтернативы и обзор

Самоописание: две конкретные альтернативы оценить легче длинного списка.
Контрпример к универсальному сокращению: при знакомстве с неизвестной областью
широкий обзор полезен. Неизвестно, как предпочтение меняется под давлением срока.

Рабочее предложение ИИ: различать выбор и знакомство с областью; подбирать
масштаб ответа по текущей задаче. Это способ участия, не установленное свойство.

## Временное состояние

Усталость сообщена для отдельного дня. Постоянная утомляемость не установлена.
```

## Возможный STARS.md

```markdown
# Личный контекст

Редакция: 2026-09-12.

## Участие

Давай пространство для самостоятельной мысли. Подбирай ширину ответа по задаче:
помочь выбрать и познакомить с областью — разные обращения.
Не принимай молчание за отказ, а временную усталость — за черту личности.

## Самоописание

Предпочитает сначала поработать молча. При выборе легче оценить две конкретные
альтернативы; при изучении нового полезен широкий обзор. Не превращай это
в обязательное число вариантов. Новая просьба важнее этого обобщения.

## Основания

Полное основание — STARS.full.md рядом с этим файлом. Открой его для уточнения
условий и контрпримеров; перед пересборкой прочитай целиком. Не читай автоматически.
Если файл недоступен, не достраивай отсутствующее. Астрологического слоя нет.
Личные сведения не передавай и не копируй без просьбы.
```

В настоящем комплекте имя полного файла оформляется рабочей относительной ссылкой.
Инструкция подключения находится в окружении пользователя и указывает на его собственный
каталог, а не на этот пример. Пример показывает отбор и оговорки, но не доказывает,
что ответ ИИ станет лучше: это выясняется в отдельной рабочей сессии и по отклику человека.
