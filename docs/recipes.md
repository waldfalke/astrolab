# Что разобрать с Astrolab

[Натальная карта](#natal) · [Синастрия](#synastry) · [Соляр](#solar) · [Транзиты](#transits) ·
[Мунданные астрологические часы](#city-day) · [Личный прогноз дня](#day)

Для большинства расчётов нужен [запущенный Astrolab](../README.md#запуск-в-docker)
и агент с доступом к его MCP-серверу. Способ подключения зависит от приложения;
локальный адрес сервера — `http://127.0.0.1:8400/mcp`.
Если подключение недоступно, агент должен сказать об этом, а не придумывать расчёт.
Синастрия пока запускается отдельным локальным рецептом из исходников.

Передай агенту одно из поручений ниже. Он уточнит исходные данные и сверится
с [описанием инструментов](mcp-api.md). Дата, время и место рождения — личные данные:
передавай их только в подходящую тебе среду, не в публичные обсуждения и примеры.

## Общие правила для агента

- Сначала проверь доступные инструменты и их схемы. Числа, положения и даты бери
  из ответов Astrolab; сохраняй исходные параметры вместе с результатом в согласованном месте.
- Уточняй часовой пояс на дату рождения и координаты места. Не подставляй полдень
  вместо неизвестного времени. Объясни, какие части разбора при такой неопределённости недоступны.
- Отделяй расчёт от астрологического толкования и от слов человека. Не подгоняй его историю
  под карту; отмечай альтернативы и пределы вывода. Астрология не является научно подтверждённым
  способом предсказывать события и не заменяет профессиональных рекомендаций.

<a id="natal"></a>

## Натальная карта

Связное чтение карты вместо списка значений каждой планеты.

```text
Помоги мне разобрать натальную карту с Astrolab.
Прочитай docs/recipes.md и docs/mcp-api.md.
Уточни дату, точное время и место рождения, а также что мне интересно понять.
Проверь перевод времени в UTC и рассчитай natal.
Сначала покажи несколько основных связей карты, затем разбери их вместе со мной.
Для каждого толкования назови расчётное основание и не выдавай его за факт обо мне.
Не делай выводов о домах и углах, если точности времени для них недостаточно.
```

**На выходе:** основные темы карты, их расчётные основания и вопросы для дальнейшего разговора.
Если захочешь сохранить полезное для общения с ИИ — [сделай свой STARS](stars/README.md).

<a id="synastry"></a>

## Синастрия

Чтение отношений двух людей без предположения, что отношения обязательно романтические.
Один и тот же расчёт можно разбирать для пары, друзей, родственников или двух коллег.
Первая версия требует точного времени и места рождения обоих участников.

Установи дополнительную группу и Chromium для PDF:

```powershell
uv sync --frozen --group engine-a --group synastry
uv run playwright install chromium
pwsh infra/ephe/get-ephe.ps1 -Source web

$env:SWISS_ENGINE = "a"
$env:SWISS_EPHE_PATH = (Resolve-Path "infra/ephe/files").Path
$env:REQUIRE_ENGINE_A = "1"
```

Сохрани вход в `.private/synastry-input.json`. Время уже должно быть переведено в UTC:

```json
{
  "participants": {
    "A": {
      "id": "person-a",
      "datetime_utc": "1990-03-21T12:00:00Z",
      "latitude": 48.8566,
      "longitude": 2.3522
    },
    "B": {
      "id": "person-b",
      "datetime_utc": "1992-09-23T18:30:00Z",
      "latitude": 35.6762,
      "longitude": 139.6503
    }
  }
}
```

Рассчитай пакет и два взаимных вида карты:

```powershell
uv run python artifacts/mcp-recipes/synastry_local.py `
  --input .private/synastry-input.json `
  --output .private/synastry-calculation

uv run python artifacts/renderer/render_synastry.py `
  --bundle .private/synastry-calculation `
  --output-dir .private/synastry-visuals `
  --label-a "Участник A" `
  --label-b "Участник B"
```

Затем передай агенту такое поручение:

```text
Подготовь чтение синастрии по рассчитанному пакету.
Прочитай docs/synastry-reading-recipe.md и пустое основание
artifacts/report-templates/synastry-astrology.md.
Используй natals/A.json, natals/B.json, cross_aspects.csv и overlays.csv.
В каждом натале обязательно рассмотри phases: это состояние объектов исходной карты,
а не отдельная «фаза пары». Сначала заполни основание с расчётами, альтернативами
и ограничениями, затем напиши связный текст для читателя.
Учитывай указанный контекст отношений, но не подгоняй под него расчёт.
Не утверждай чувства, согласие или намерения другого человека как известный факт.
```

Сохрани результат агента как `.private/synastry-reading.md`, а заполненное основание —
как `.private/synastry-astrology.md`. Собери самодостаточный HTML и PDF:

```powershell
uv run python artifacts/renderer/assemble_synastry.py `
  --bundle .private/synastry-calculation `
  --visuals .private/synastry-visuals `
  --reading .private/synastry-reading.md `
  --twin .private/synastry-astrology.md `
  --art assets/synastry.png `
  --output-dir .private/synastry-report `
  --title "Синастрия двух людей" `
  --label-a "Участник A" `
  --label-b "Участник B" `
  --pdf
```

**На выходе:** расчёт с фазами обеих карт, межкартные аспекты, оба направления
наложений на дома, два взаимных колеса и проверяемый HTML/PDF с исходным чтением.
Личные входы и результаты остаются внутри `.private`.

<a id="solar"></a>

## Соляр

Год от возвращения Солнца к его натальному положению, а не от первого января.

```text
Помоги мне разобрать соляр с Astrolab.
Прочитай docs/recipes.md и docs/mcp-api.md.
Уточни данные рождения, нужный год и место, для которого строим соляр.
Рассчитай natal и solar_return. Покажи точный момент возвращения Солнца
и использованное место. Если место отличается от места рождения, задай обе
координаты соляра явно; не выбирай их молча.
Свяжи главные темы соляра с натальной картой и годовой профекцией из ответа.
Собери несколько ведущих тем года с основаниями, а не обещания конкретных событий.
```

**На выходе:** карта соляра, темы личного года и связь с наталом и профекцией.

<a id="transits"></a>

## Транзиты

Что длится месяцами, что проходит быстро и почему один аспект может возвращаться несколько раз.

```text
Помоги мне разобрать период по транзитам с Astrolab.
Прочитай docs/recipes.md и docs/mcp-api.md.
Уточни данные рождения, начало и конец периода и интересующую меня тему.
Рассчитай natal и transits, передав границы периода в UTC.
Раздели длительный фон и точные прохождения; объедини повторные прохождения
одной связи в последовательность. Покажи даты и расчётные основания.
Сначала дай обзор периода, затем предложи, что стоит разобрать подробнее.
Не называй аспект гарантией события. Укажи, что этот инструмент не включает Луну
и не даёт полного почасового прогноза дня.
```

**На выходе:** хронология периода с точными прохождениями и длительными окнами действия аспектов.

<a id="city-day"></a>

## Мунданные астрологические часы

Прогноз на день для выбранного города по смене восходящих знаков. Данные рождения
не нужны: это не личный прогноз и не натальная карта города.

```text
Составь мунданный прогноз на выбранный день для города с Astrolab.
Прочитай docs/recipes.md и docs/mcp-api.md.
Уточни город и местную дату. Определи координаты и смещение часового пояса
для этой даты, затем рассчитай rising_hands.
Покажи двенадцать восходящих знаков в порядке суток и собери из них связный ход дня.
Отделяй общий астрологический смысл от того, что действительно зависит от места.
Не приписывай всем жителям одинаковое событие и не превращай расчётную минуту
смены знака в обещание события.
```

**На выходе:** мунданный прогноз для названного города с двенадцатью
астрологическими часами и местным временем их начала.

<a id="day"></a>

## Личный прогноз дня

День рассматривается непрерывно, а не как одна карта на полдень:

- длительные транзиты задают фон;
- движение Луны показывает изменения внутри дня;
- прохождения ASC и MC по натальным точкам уточняют время;
- двенадцать восходящих знаков делят сутки на неравные интервалы;
- совпадения нескольких указаний выделяют узловые часы.

При наличии соляра можно увидеть и то, как день связан с темами года.
Точность временных выводов зависит от точности рождения и выбранного места наблюдения;
расчёт до минуты не делает толкование достоверным прогнозом события.

`rising_hands` рассчитывает двенадцать интервалов восходящих знаков. Для личного
прогноза к ним добавляются натальная карта и остальные перечисленные выше слои.
